## Wapas aakar yahan se shuru karein

1. **Transcript Only** ka option add karein. Timestamp ke saath Original English transcript ya Roman Urdu tarjuma download ho. Is mode mein nayi audio ya video render na ho.
2. **Pakistani Urdu ki awaaz behtar karein.** Tootay ya dohraye gaye alfaaz aur tez bolne ke clips timestamps ke saath jama karein. Text aur awaaz alag check karein. DNS aur CDN jaise technical terms bhi test karein.
3. **Mazeed zabanain.** Language selector mein pehle ek nayi zaban add karein. Us ka tarjuma aur awaaz test kar ke phir doosri zabanon par kaam karein.
4. **Portfolio demo.** khalidkhan.me par Urdu Dub Studio ka demo aur Docker download link rakhein.
5. **Browser trial aur kamai.** Alag server par chhota trial sochain jahan log apni ya ijazat wali files upload kar sakein. Docker version free rakhne aur hosted version mein limited free trial ke baad per-minute credits dene ka option hai. Pricing se pehle processing cost naapain.

Abhi project ka kaam pause hai. Agli session ka pehla step Transcript Only hai.
